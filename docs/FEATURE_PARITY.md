# macOS 与 Windows 功能对照

此表用于公开说明 Windows 版的移植范围。除 Windows 平台替代方案和项目明确移除的能力外，核心数据与工作流应与 macOS 版保持一致。

| 能力 | Windows 状态 | 说明 |
| --- | --- | --- |
| 今天、逾期、待安排、已完成 | 已实现 | 已完成任务统一置底 |
| 任务新增与编辑 | 已实现 | 名称、备注、全天、具体时间、日期范围与重复规则 |
| 任务右键操作 | 已实现 | 延后一天、编辑、忽略当前逾期、删除 |
| 周历与月历 | 已实现 | 导航、拖放排期、单日详情与快捷新增 |
| 自然语言快速输入 | 已实现 | 支持中文日期时间并显示识别预览 |
| 个人 DDL 与正向里程碑 | 已实现 | 支持具体时间、编辑、忽略、恢复与删除 |
| CCFDDL | 已移除 | 按项目要求不联网读取会议数据 |
| 投入时间打卡 | 已实现 | 开始、结束、超长记录检查、修正、编辑与删除 |
| 习惯 | 已实现 | 每周目标、多次打卡、撤销、新增、编辑与删除 |
| 数据看板 | 已实现 | 日/周/月趋势、任务完成率、习惯统计与单日最长累计时长 |
| 科研、工作、学习模式 | Windows 扩展 | 配色、图标、输入提示、打卡与看板文案联动 |
| macOS 灵动岛 | Windows 替代 | 使用可被普通窗口遮挡的紧凑浅色桌面卡片 |
| Apple 日历同步 | 已移除 | 按项目要求不提供 |
| 日程提醒 | 已移除 | 按项目要求不提供 |
| 本地数据与备份 | 已实现 | JSON 持久化、导入导出和示例工作区 |
| 系统设置 | 已实现 | 主题、默认日历视图、开机启动与桌面卡片 |

发现 macOS 已有、此表未列出且不属于明确移除范围的功能时，欢迎提交 Issue，并附上入口、预期行为和复现步骤。
