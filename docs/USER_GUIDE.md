# 研序 Windows 使用指南

研序把任务、计划日历、专注时间、习惯和截止日期放在同一张工作台中。所有数据默认只保存在本机。

## 1. 工作区模式

打开右上角“设置”，可选择三种模式：

- **科研模式：** 论文、实验和学术计划，使用蓝色与烧瓶图标；
- **工作模式：** 项目、会议和专注时间，使用紫色与公文包图标；
- **学习模式：** 课程、复习和学习节奏，使用青绿色与书本图标。

模式会改变主色、快捷输入提示、打卡区和记录看板文案。任务、习惯、DDL 与时间记录在三种模式间共享，切换不会丢失数据。

## 2. 顶部数据看板

顶部三张卡片展示：

- 本周投入时长、最早开始、最晚结束和最长单次；
- 本周任务完成数量与完成率；
- 本周习惯进度。

点击右上角“详细记录”可按日、周或月查看时间趋势、任务完成率和习惯记录。

## 3. 今天

左侧按以下顺序显示任务：

1. 已逾期；
2. 今天；
3. 未安排；
4. 已完成。

完成任务后，它会自动移动到列表和日历的最后。再次点击复选框可恢复未完成状态。

顶部输入框支持中文快速输入，例如：

| 输入 | 结果 |
| --- | --- |
| `整理实验数据` | 进入待安排 |
| `今天整理实验数据` | 创建今天的全天任务 |
| `明天下午2点开会` | 创建明天 14:00 的固定时间任务 |
| `下周五下午2点开组会` | 创建下周五 14:00 的固定时间任务 |

## 4. 周历与月历

- 使用工具栏切换周视图和月视图；
- 将任务拖到某一天可重新安排日期；
- 点击日期列中的“添加”可直接在该日创建任务；
- “待安排”抽屉保存还未决定日期的任务；
- 支持某一天、具体时间、日期范围以及每天、每周、每月重复。

## 5. 时间与习惯

右侧第一张卡片用于记录当前模式下的投入时间。点击“开始”建立新时段，点击“结束”完成记录。可在“详细记录 → 打卡记录”中编辑或删除时段。

习惯按周设置目标，同一天可多次打卡，也可以撤销最近一次记录。右侧显示本周进度，详细记录页提供完整的习惯管理。

## 6. DDL 与里程碑

- 个人 DDL 显示距离目标日期的天数；
- 日期过去后会显示已经过去的天数；
- 正向里程碑用于记录某项行动已经持续多久；
- Windows 版不连接 CCFDDL，也不会下载外部会议数据。

## 7. 设置与备份

设置中心支持：

- 科研、工作、学习模式；
- 跟随系统、浅色和深色主题；
- 默认周视图或月视图；
- 登录 Windows 时启动；
- 打开本地数据位置；
- 导出或导入 JSON 备份；
- 恢复示例工作区。

“恢复示例工作区”会替换任务、记录、习惯和 DDL，但会保留当前主题、默认日历视图与工作区模式。执行前请先导出备份。

## 8. 数据位置

默认数据文件：

```text
%APPDATA%\yanxu-windows\data.json
```

删除应用不会自动删除该文件。需要彻底清理时，请先退出研序并确认备份，再手动处理数据目录。
